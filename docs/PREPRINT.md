# Draft preprint

**Reliable motor imagery EEG transfer through verified event timing and label-free participant alignment**

[Read the full manuscript](MANUSCRIPT.md) · [Abstract](ABSTRACT.md) · [External results](../results/physionet_external_v4/REPORT.md)

Status: **draft preprint, not peer reviewed**, hosted in this GitHub repository.
It has not been submitted to an external preprint server and has no claimed DOI.
The repository commit history identifies revisions; use a specific commit when
referencing a version.

The work provides a reproducible EEG decoding pipeline, participant-separated
source validation and a frozen external comparison. The five-participant
PhysioNet evaluation is provisional: aligned CSP reached mean balanced accuracy
0.6044 (95% participant-bootstrap interval 0.4332–0.7658), versus 0.5614 for the
RMS/CSP baseline. The paired improvement interval includes zero. These results
do not establish reliable population generalization.

Alignment uses an unlabeled target-participant batch. It is distinct from
strict source-only inductive inference. Hypotheses were described retrospectively
and were not preregistered. Negative outcomes and limitations are retained in
the manuscript and linked results.
